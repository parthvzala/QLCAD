### Getting the source and relinking

Each QLCAD release offers these from the same place as the app:

- the complete source of the OCCT version it uses, as `OCCT-source.tar.gz`
- QLCAD's complete source, including the build scripts

To build QLCAD against a modified OCCT, you need macOS on Apple Silicon, the Xcode Command Line
Tools, and CMake through [mise](https://mise.jdx.dev/):

1. Extract `OCCT-source.tar.gz` into `.occt/`, so that the source is in `.occt/src`.
2. Make your changes to `.occt/src`.
3. Run `./scripts/build_occt.sh` to compile OCCT. It keeps existing source.
4. Run `./scripts/build.sh` to relink. The app is written to `build/QLCAD.app`.
